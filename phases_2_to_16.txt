=================================



Create or improve the Business Profile system.



Collect information such as:



• Business/profession type

• Industry

• Business activity

• State

• District

• Location

• Premises type

• Owned / Rented / Leased / Consent or Shared

• Approximate investment

• Employee count

• Machinery/equipment

• Electricity requirement

• Water usage

• Food handling

• Manufacturing activity

• Construction activity

• Storage activity

• Vehicle/logistics activity

• Other configurable sector-specific questions



Use progressive disclosure.



Do NOT show 30 questions at once.



Ask only relevant questions.



Example:



If user selects Food Processing:



show food-related questions.



If user selects IT/Software:



do not show irrelevant food/machinery questions.



If user selects Manufacturing:



show relevant manufacturing questions.
